# Phase 10B Excel 导出

接口 `GET /api/reports/{type}/export`，接受与页面报表完全相同的筛选条件。后端重新读取当前用户和数据范围，先按相同查询计算行数，超过 **50,000 行**时返回 400 并要求缩小筛选范围；不截断数据。`page`/`size` 参数仅接受合法值，不改变“导出全部筛选结果”的含义。

导出使用 Apache POI `poi-ooxml` 5.4.1（Java 17 兼容）。原 POM 没有 Excel 依赖，因必须生成真实 `.xlsx` 而新增该单一 Excel 库；不引入报表框架或第二个 Excel 库。`SXSSFWorkbook` 在内存保留 100 行，Mapper 每批读取最多 500 行，按与网页相同的稳定排序写入；写入结束释放 SXSSF 临时文件。最终 HTTP 响应为 XLSX 字节，单次上限仍可能占用一定响应内存，需在实际大数据量场景监测。

工作表名为“业务报表”，包含中文表头、冻结首行、自动筛选和固定合理列宽。数量为数值单元格，时间为 Excel 日期单元格并统一显示 `yyyy-mm-dd hh:mm:ss`；编码、SN、业务单号等采用文本单元格以保留前导零并避免被当作公式。文件名由服务端固定报表类型与当前日期构成，使用 UTF-8 `Content-Disposition`，没有用户输入参与文件路径或文件名。浏览器通过原生 fetch 下载，不引入 Axios。

生成过程只读数据库；导出失败不产生文件下载。HTTP 401/403 沿用现有前端鉴权事件，其他业务错误显示服务端提示。真实文件读取验证及已知限制见 [phase10b-verification.md](phase10b-verification.md)。
